# Лабораторная №6 - поиск в пространстве состояний

Вариант №6. Три переключателя, каждый ход меняет один бит. Цель по умолчанию: перейти из 000 в 111.

## Запуск

1. На GitHub нажмите **Code → Download ZIP** и распакуйте архив.
2. Откройте **Inteligenta-Artificiala → lab-06 → index.html**.
3. Выберите начальное и целевое состояние, затем нажмите **Рассчитать**. В списке под графом можно выбрать стратегию для просмотра её пути.

Установка и интернет для запуска не нужны. Программа сравнивает BFS, DFS, A*, обратный BFS и смешанную стратегию. На графе выделяется найденный маршрут.

- [PDF-отчёт](Report-Lab-06.pdf) с формализацией, псевдокодами, измерениями и приложением с исходным кодом.
- [model.js](model.js) содержит модель и стратегии поиска.
- [app.js](app.js) строит граф и таблицу в браузере.
