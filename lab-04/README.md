# Лабораторная работа №4 - Inteligența Artificială

Вариант №4. Прогнозирование изменения цен на энергию методом Мамдани.

[Скачать PDF-отчёт](./Report-Lab-04.pdf?raw=true) · [Открыть исходный код модели](./model.js)

## Запуск

1. Скачайте репозиторий через **Code → Download ZIP** и распакуйте его.
2. Откройте `Inteligenta-Artificiala/lab-04/index.html` в браузере.
3. Введите индексы спроса и предложения (0-100) и инфляцию (0-20 %), затем нажмите **Рассчитать**. Готовые примеры доступны в списке сценариев.

Для запуска достаточно браузера. Страница работает локально без установки зависимостей.

## Что делает программа

Модель вычисляет степени принадлежности входов, активирует 27 правил IF-THEN и объединяет их выводы. Каждое правило учитывает спрос, предложение и инфляцию. Для AND используется минимум, для агрегации выводов — максимум. Из объединённой функции программа получает изменение цены методом центроида. Интерфейс показывает результат, его категорию, графики функций принадлежности и силу каждого правила.

Линейный график меняет инфляцию при фиксированных спросе и предложении. Тепловая карта меняет спрос и предложение при фиксированной инфляции.

| Спрос | Предложение | Инфляция | Изменение цены |
|---:|---:|---:|---:|
| 15 | 85 | 3 % | -5,52 % |
| 50 | 50 | 4 % | +1,68 % |
| 90 | 15 | 3 % | +6,88 % |
| 50 | 50 | 12 % | +4,97 % |
